# First Six Weeks

This is a proposed sequence, not completed progress. Move forward when the evidence is ready rather than merely when a week ends.

| Stage | Work | Evidence needed before moving on |
| --- | --- | --- |
| Weeks 1–2 | Learn basic CAD; sketch and build a manually moved single-joint simulated leg | Dimensions, secured mounting, load locations, free-body diagram, physical travel limits, photos |
| Week 3 | Install angle sensing and record manual motion | Calibration against known angles, repeated readings, timestamps, plot |
| Week 4 | Install force sensing and measure manual cable pulls | Correct sensor mounting, zero/calibration checks using known loads, repeated tests, raw data |
| Weeks 5–6 | Estimate required loads; select compatible drive components; implement limited powered movement | Reviewed electrical and mechanical setup, guarding, stop behavior, limited-range trials, force/angle logs |

If parts or learning take longer, extend the schedule. The first objective is reliable measurement, not a visually complete exoskeleton.

## First session

1. Read the scope and safety boundary in the README.
2. Draw a base, one pivot, and one simulated leg.
3. Label dimensions, center of mass, movement range, and cable attachment options.
4. List existing tools and missing parts.
5. Create a dated notebook entry with Linda's own explanation of the project.
6. Do not order a motor yet.

## First powered-test readiness review

- Rig is clamped or bolted down.
- Masses and fasteners are secured.
- No body part can enter the moving mechanism during operation.
- Mechanical stops and guards are installed.
- Electrical compatibility and limits have been checked.
- Power-isolation and post-stop behavior have been tested without a hazardous load.
- Sensor readings are credible and do not saturate over the intended test range.
- A specific test range, speed, and abort condition have been written down.
- An appropriately competent adult supervises the initial run.

## After the first baseline

Select one question, such as whether cable routing or an elastic element changes force peaks and inactive resistance. Preserve the baseline design and test procedure so later versions can be compared fairly.

Before expanding toward human use, arrange separate professional engineering and clinical review. Do not attach an early prototype to a person.
